🔑 Gemini API key của bạn

Trạng thái: Chưa có key

Key được mã hóa (AES-GCM) và chỉ lưu trên trình duyệt này. Mỗi lần hỏi, key được gửi kèm request tới server để gọi Gemini — server không lưu, không ghi log key. Mã hóa chỉ chống đọc trộm dữ liệu trình duyệt, không thay thế việc giữ máy an toàn.

Cách tạo key (miễn phí)
  1. Mở aistudio.google.com/apikey, đăng nhập Google.
  2. Bấm Create API key, chọn (hoặc tạo) một Google Cloud project.
  3. Copy key, dán vào ô trên rồi bấm Lưu.

Key gói miễn phí có giới hạn số request/phút và /ngày. Đọc điều khoản Gemini API về cách Google dùng dữ liệu ở gói miễn phí — không hỏi nội dung bí mật/nội bộ.

Cách xóa / thu hồi key
  1. Xóa khỏi trình duyệt này: bấm nút "Xóa key khỏi trình duyệt này" ở trên. Thao tác này không vô hiệu hóa key phía Google.
  2. Thu hồi hẳn: mở aistudio.google.com/apikey, bấm biểu tượng thùng rác cạnh key → key ngừng hoạt động ở mọi nơi.
  3. Nghi key bị lộ → thu hồi ngay rồi tạo key mới.
